# macOS feature parity

This table compares the Windows app (`src/QNotch/`) with the native Mac app (`src/QNotch.Mac/`). The "Windows feature" column describes what the Windows code actually does. Feasibility is the honest ceiling on macOS:

- **full**: the same behavior through a public API.
- **partial**: something real but narrower; the table says what is missing.
- **not possible**: needs a private framework, an entitlement Apple doesn't grant, or a permission that doesn't fit the feature.

A feature counts as at parity only when its Status says **done**. Inventory taken 2026-10-16 from `main` at `e7b782d`.

## Proposed order

High value and low risk first. Each step is one module (or one shell feature), one commit.

1. **Shell foundation**: a generic Features page (`disabledModules`), a Sounds registry and page, a Hotkeys registry with Carbon hotkeys (⌃⌥N toggle, ⌃⌥F search) and recorder page. Every later module needs these.
2. **Volume**: event driven, no permission.
3. **Note**: local, atomic.
4. **Color picker**: `NSColorSampler`, no permission.
5. **Mic and camera**: listeners only, no permission.
6. **System stats**: card sampled only while visible; wings opt-in.
7. **General/Appearance completion**: pin, hover/close delays, accent, profile photo, card visibility, autostart (`SMAppService`).
8. **File tray**: drag and drop, Quick Look thumbnails, Share/AirDrop.
9. **Clipboard history**: once the polling interval is agreed.
10. **Notifications**: CLI, socket, loopback HTTP, Keychain token, glance-as-peek.
11. **Agents**: hooks, socket, libproc, T3 read-only SQLite. Peek and sounds land here.
12. **Weather** and **GitHub**: once network use is agreed.
13. **AI apps and usage**: once the Keychain question is answered.
14. **Edit mode** (cards and tabs), then **Game mode**.
15. **Scheduled** (launchd).
16. **Now playing**: depends on your decision.
17. **Deferred**: Updates install (signing, Sparkle), Phone-share LAN server, Setup codes, notch nudge on non-notched displays.

## Decisions (2026-10-16)

1. Network: Weather (api.met.no, yr.no), GitHub (api.github.com) and AI usage (api.anthropic.com) may make the same requests as on Windows.
2. Claude Code token: read the "Claude Code-credentials" Keychain item; the one-time macOS access prompt is acceptable. `.credentials.json` is the fallback.
3. Clipboard: a 1 s `changeCount` check is accepted while Clipboard is enabled (with timer tolerance). It is the documented exception to "no repeating idle timers".
4. Now playing: Music and Spotify through Apple Events (Automation prompt per app). No private MediaRemote.
5. Wings: System stats shows in the wings, with a toggle.
6. AI slot hotkeys default to ⌃⌥1…6.

Still open (aggregated for later): Sparkle and Developer ID signing for updates; the Phone-share LAN server versus AirDrop only; CoreLocation for weather.
